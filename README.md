# Goodies Stack

A web collection with ten free utilities, a subscription app catalogue and additional products in development.

[Goodies Stack at Burrito’s Labs](https://goodiesstack.com/)

## Technology

Astro, TypeScript, CSS and browser APIs for the free-tool catalogue.

## Architecture

The hub groups tools by job. Each free utility has a dedicated interface and runs its calculation or interaction in the browser. Account-backed subscription apps have their own product workflows.

## Product behavior

The free utilities require no account. Individual tools describe whether they store settings or inputs in the browser.
